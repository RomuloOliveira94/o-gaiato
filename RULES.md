# 📜 Regras do Jogo — O Gaiato

"O Gaiato" é a versão brasileira do clássico jogo de dedução social (estilo *Spyfall*/"undercover"): todo mundo sabe a palavra secreta, menos uma pessoa — **O Gaiato**. Ele precisa se disfarçar, e os outros precisam descobrir quem ele é.

## 🎯 Objetivo

- **Jogadores:** descobrir, através das dicas ditas em voz alta, quem é O Gaiato antes da votação.
- **O Gaiato:** disfarçar-se bem o suficiente para não ser descoberto na votação (ou torcer por um empate).

## 🕹️ Como jogar (setup)

Ao iniciar a partida, o jogo sorteia automaticamente:

1. **Um tema (categoria)**, entre as categorias cadastradas (ex.: Filmes, Séries, Música, Esportes, Games...).
2. **Uma palavra secreta** dentro daquele tema.
3. **Um jogador para ser O Gaiato** (o espião), sorteado entre todos os participantes da partida.

Tudo isso é feito pelo app — ninguém escolhe, é sorte.

## 👀 O que cada jogador vê

| | Tema | Todas as palavras da categoria | Palavra secreta |
|---|:---:|:---:|:---:|
| **O Gaiato** | ✅ | ✅ | ❌ |
| **Jogadores normais** | ✅ | ✅ | ✅ |

- **O Gaiato** vê o tema e a lista completa de palavras da categoria, mas **não sabe qual delas é a secreta**. Ele precisa "advinhar" ouvindo as dicas dos outros.
- **Os demais jogadores** veem o tema, todas as palavras da categoria **e** a palavra secreta.

## 💬 Rodada de dicas

Durante o jogo, os jogadores se revezam dando **dicas verbais** sobre a palavra secreta — em voz alta, na mesma sala, olhando uns para os outros.

> ⚠️ **Importante:** as dicas são combinadas presencialmente e **não são registradas nem controladas pelo app**. O Gaiato usa o que ouve dos outros para tentar se misturar; os demais jogadores usam as dicas para tentar identificar quem não sabe a palavra de verdade.

O app não impõe ordem de fala nem cronômetro — isso fica a critério do grupo.

## 🗳️ Votação

Quando o grupo sentir que já discutiu o suficiente, cada jogador registra seu voto no app, apontando quem acha que é O Gaiato.

Assim que **todos os jogadores votarem**, a partida termina automaticamente e o resultado é revelado.

## 🏆 Condições de vitória

- **Jogadores vencem** se o jogador mais votado for, de fato, **O Gaiato**.
- **O Gaiato vence** se:
  - a pessoa mais votada **não** for ele, **ou**
  - a votação terminar **empatada** entre dois ou mais jogadores.

## 👥 Número de jogadores

- **Mínimo: 3 jogadores** para iniciar a partida.
- **Sem máximo** — chame quantos amigos quiser para o grupo.
